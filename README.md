# Job Application Tracker

A command-line Python application for recording and managing job applications.

## Features

- Add a new job application
- Save company, role, location, date applied and status
- View saved applications
- Update an application's status
- Store application data locally in JSON format

## Technologies used

- Python
- JSON
- `pathlib`

## How to run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python tracker.py
